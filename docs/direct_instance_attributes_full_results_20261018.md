补充评测限制（共同链路审查）：实际官方PQ库会忽略预测void覆盖超过一半的未匹配GT，并在IoU union中扣除预测void覆盖GT部分。因此PQ不等于固定全GT召回。CPU检查已有128场景PNG：target有效GT上的void覆盖率6.36%→7.61%，但被忽略的未匹配thing GT为62/507→58/507，新组反而更少。不能把本次PQ增益直接归因于忽略更多GT，也不能把它直接当作完整实例质量改善。原官方数值保留不变，详见[共同失败链路审查](shared_failure_audit_20261018.md)。

## 下一步判断

1. 新结构可训练、具备全量泛化能力；不能以小数据短训失败直接否定它。
2. 当前等预算正式结果不足以替换原基线，8维直接属性/原型＋渲染监督的组合尚未带来整体收益。原全量基线不含67050渲染监督，因此不能单独归因于“直接属性”或“8维原型”。
3. 在原型和固定HDBSCAN两条读出中，继续以原型为主，聚类留作辅助对照；不能将8窗口结果推广成128场景聚类排名。
4. 比起立即加长训练，更值得先固定这两份全量checkpoint，按相同128场景分阶段定位AP差异及类别/分数/重复/组装影响。该后续诊断尚未提交，本轮没有增加实验组或续训。

限制：一次种子、原节点11与新节点13同8×3090、不声称GPU前端逐位确定性；辅助探针仅4train+4heldout且两个视图不是独立统计样本。全量4epoch反映当前配方，不证明所有初始化、损失权重或聚类设置都无效。
