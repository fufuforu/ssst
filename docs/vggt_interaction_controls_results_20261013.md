四组训练、四组自动官方评测、汇总及保存状态审计全部 `COMPLETED / 0:0`。
三种写回改动均未带来重建与理解的整体提升。关闭写回损害 RGB 重建；
门控有 mAP 收益，但趋于全开；独立注意力的 PQ 下降。
当前证据不足以认定 object query 无法利用几何，也不足以认定当前结构已经达到上限。

## 三种改动分别说明什么

1. **关闭写回**：相对原双向，PSNR −0.47744 dB；64 场景中 19 个改善、45 个下降。
   对固定预测做 10000 次场景配对 bootstrap，95% 描述性区间为
   [−0.73272, −0.20476] dB。LPIPS 改善 0.00384，输入/新视图 mIoU 分别
   +0.704/+0.700 个百分点，但新视图 mAP −0.514、PQ −0.475 个百分点。
   写回在此预算下对 RGB 重建有帮助；直接删除写回不能解决整体指标偏低。
   本组仍训练完整理解损失，理解梯度仍可经读取路径进入 GS/adapter，
   因此不能把它当作“移除理解损失”的对照。
2. **门控写回**：输入/新视图 mAP +2.982/+1.841 个百分点，但 mIoU
   −0.739/−0.900、PQ −0.173/−0.723 个百分点。PSNR 差 −0.01936 dB，
   场景 bootstrap 区间 [−0.18544, +0.14910]，不足以判断小差异可重复。
   新视图逐类 AP 为 8 类上升、8 类下降、2 类不变；较大收益来自 toilet
   (+18.22 pp)、curtain (+14.85 pp)、desk (+14.75 pp)，没有全面改善。
   这组有实例 AP 的局部收益，尚不适合替换整体基线。
3. **独立注意力写回**：PSNR 差 −0.05880 dB，区间 [−0.19166, +0.07738]；
   输入/新视图 PQ −2.527/−3.063 个百分点。mAP +0.965/+0.703 pp，
   mIoU −0.426/−0.449 pp。新视图 PQ 12 类下降、8 类上升。
   并未支持“只要把写回从 mask embedding 的点积换成独立 QKV 就能改善”。
   独立注意力同时增加 1052672 个参数，不能将所有变化单独归因于路由方式。

Bootstrap 只表示此验证场景集合上的抽样变化，未覆盖训练种子不确定性，
也没有给全局 mAP/PQ 构造错误的逐场景平均置信区间。
小样本类别的大幅 PQ 波动需要后续完整验证确认。

## 门控与写回强度

门控初始化为 0.9，最后 100 步四个 rank 的已记录 microbatch 均值：

|---|---:|---:|---:|
| 6 | 0.99996588 | 0.98974741 | 0.02499411 |
| 8 | 0.99991341 | 0.99758303 | 0.02499780 |
| 10 | 0.99993475 | 0.99742955 | 0.02499834 |
| 12 | 0.99995458 | 0.99522936 | 0.02497463 |

**该门控学成了近似全开，未呈现预期的选择性抑制。** 这不等于所有门控方案都无效。
其初始化、学习目标与 sigmoid 参数化共同决定了此结果。
原版与独立注意力最后 100 步的平均写回比例也接近各层 0.025 上限；
因而结果主要反映不同写回方向/路由，不能从“有 norm cap”推断实际写回很弱。
日志每个 rank/update 只保留最后一次 microbatch 的 token 均值与极值；
这些统计不是全训练 token 的完整分布，也没有测量 GS→query 正向几何读取的有效性。

## 更值得追查的共同退步

四组从共同起点到 500 步，PSNR 均下降 0.38–0.86 dB；输入 mIoU 下降
4.01–5.45 pp，新视图 mIoU 下降 3.45–5.05 pp。AbsRel/RMSE 均改善。
门控 mAP 超过共同起点，但没有同步改善语义与全景分割。

下面对比第 1 个完整训练遍历（1–64 步）与第 7 个完整遍历（385–448 步），
两次均完整曝光同一组 512 窗口。表中理解损失为原始记录值，未乘理解 warmup 权重。

| 对照 | 重建训练损失：第1→第7遍历 | 理解训练损失：第1→第7遍历 |
|---|---:|---:|
| 原双向 | 0.02852 → 0.02720 | 0.22613 → 0.18110 |
| 关闭写回 | 0.02851 → 0.02660 | 0.22909 → 0.18506 |
| 门控写回 | 0.02853 → 0.02750 | 0.22658 → 0.18139 |
| 独立注意力写回 | 0.02850 → 0.02697 | 0.22703 → 0.18538 |

训练拟合改善而验证理解退步，使泛化、预训练理解特征漂移、训练目标与评测行为
以及跨任务梯度作用成为共同排查重点。原双向在 300→500 步保持饱和 beta，
PSNR 几乎不变，但新视图 mIoU 从 0.6424 降至 0.6131，mAP/PQ 也下降。
不能仅以“还没有收敛”解释这些趋势；也不能断言所有指标随训练单调下降，
关闭写回组的 mIoU 在 300→500 步有回升。

起点 beta=0，随后按曝光 warmup 到 0.1，LR 也有 200 步 warmup；
所以 0→500 差值不是只有参数学习的干净干预。重建损失包含多个目标，
不能要求其下降必然对应 RGB PSNR 上升。
所有组 98.2%–99.4% 更新触发 clip=1，是需要记录分任务/模块梯度的线索，
不能凭 clip 频率或 loss 数值直接宣布梯度冲突。
本组没有同数据预算的仅重建对照、固定特征的独立理解对照或多训练种子，
尚不能把共同退步全部归因于理解损失、几何特征不足或某一个交互模块。

## 下一步优先级（建议，尚未提交新训练）

先保留原双向作为联合结构基线，不立即把这三种改动放大到长训练，
也不立即扩成每层交互。优先做**固定重建输出的独立理解短诊断**，
同时采集联合基线分任务/模块梯度与训练、验证理解指标。

固定重建需要冻结重建参数并关闭 query→GS 动态写回，否则理解 query
仍会改变 GS 前向输出，不能称为独立理解实验。此隔离只用于诊断。
首先比较现有视觉路径与加入现有 GS 几何读取；再用一致小预算比较直接
读取 VGGT memory、query 前视觉/几何融合。新增融合参数应有容量对照，
应检查视图、位置、分辨率和归一化对应，而非单纯追加特征。

若理解独立训练可改善而联合训练退步，优先改梯度路由、理解特征冻结策略或
交互 detach；若对齐几何融合能稳定同时改善 mIoU/mAP/PQ，再将该读取改动
接回当前双向结构。这能区分优化干扰与几何信息利用不足。
几何利用的干预应破坏特征与空间对应；同时排列 K/V 不会改变无位置
cross-attention 的结果，不能作为几何利用的有效负对照。
