## 串行诊断：先看自身链路

使用串行66603和原Unified短测各256步终点，各16训练+16验证场景，共64窗口。固定权重，8份逐张量UNCHANGED收据全部通过，参数更新0。同窗口RGB、GT身份/类别一致。原Unified只作辅助参照，架构/训练策略不同，不是单变量对照；更不能与完整4epoch结果直接比较。

### 1. Mask在组装之前已经弱，之后继续丢失

下表是不考虑类别、每个GT取最佳Query的IoU，GT加权汇总，不是AP/PQ：

| 原生阶段 | 串行训练82 GT | 串行验证66 GT |
|---|---:|---:|
| 原始0.5 Mask | 0.1591 | 0.1030 |
| alpha过滤 | 0.1591 | 0.1030 |
| 类别/no-object过滤 | 0.1591 | 0.1030 |
| NMS后 | 0.1553 | 0.1013 |
| 像素竞争后 | 0.1259 | 0.0638 |
| 最终面积筛选后 | 0.1106 | 0.0404 |

训练1015 Query全部通过类别条件，验证1028/1033通过；因此主要损失不是no-object过滤。验证类别正确的原始oracle IoU仅0.0464（不要求类别时0.1030），说明验证分类仍是额外问题，不能说分类完全正常。

训练423/1015（41.7%）、验证490/1033（47.4%）Query在所有Gaussian上的最高membership都低于0.5。经过渲染，无任何像素达到0.5的Query增至551/1015（54.3%）和735/1033（71.2%）。有无alpha门槛结果基本相同：alpha遮挡门槛不是主因；这也不意味着每个Gaussian都可见或遮挡无影响。

验证有61个来源支持GT，但只输出14个最终实例（不是14个正确匹配）；训练73个来源支持GT只输出13个实例。原始Mask不足与竞争/面积过滤是两个连续瓶颈，不能只改最终NMS。

### 2. 重建Token弱化实例身份，但理解Decoder有部分恢复

同GT余弦减不同GT余弦（按场景平均；来源GT身份为代理，非移动后Gaussian的真实标签）：

| 状态 | 训练 | 验证 |
|---|---:|---:|
| 超点初始Token | 0.2146 | 0.2342 |
| Q_rec | 0.0689 | 0.1097 |
| LN+Linear语义seed | 0.0747 | 0.1147 |
| 理解D2 | 0.1816 | 0.1656 |
| 理解D4 | 0.2886 | 0.1414 |

D4的打乱身份负对照均值接近0（训练-0.00008、验证0.00239）；仍保留实例结构，不能称为完全Token坍缩。训练区分度在理解Decoder后恢复，验证恢复较弱；这支持保留原始超点身份作为结构改进线索，不证明重建Decoder一定有害。

Mask来源对应关系的负对照也有限：同样按场景平均的真实/打乱支持GT IoU，训练0.2380/0.2046，验证0.05396/0.05325；验证来源对应优势几乎消失。不能拿SUMMARY中GT加权真实值0.0632直接与场景均值负对照0.0533比较，也不据此宣称显著性。

最终训练好的Mask头应用于Q_rec/seed/D1-D3属于分布外辅助读出，不能根据D2高于D4便裁层或宣称后两层有害。

### 3. 降阈值能找回像素，但不是完整解决方案

串行验证来源支持GT最佳IoU：阈值0.5时0.0632；0.1时0.1783。相应正Query像素micro-recall 8.93%→60.60%，precision只有30.33%→31.75%。这些是诊断量，不是最终组装后mAP/PQ。不能据此直接更改官方阈值，更不能把变大的泛化Mask当成实例分割成功。

典型失败`scene0570_00`：47/47 Query通过类别条件，alpha>0.05覆盖100%像素；29个Query存在membership≥0.5的Gaussian，但47个Query的渲染最高概率全部<0.5，最高仅0.42266，最终实例0。正Query在GT/非GT上的平均概率仅0.1192/0.1092，区分度很弱。高membership Gaussian承担的实际渲染贡献占比按Query均值只有0.182%、最高1.739%，因此“存在高归属Gaussian”没有转化为有效可见Mask。阈值降至0.1该场景支持GT平均IoU也仅0.0882，不能用校准解释全部问题。

另一例`scene0279_02`共55 Query，类别全部通过，最终仅1实例；图中选定沙发GT的最终Mask消失。中间层颜色只作固定Query、固定最终头的辅助读出，不作训练消融证据。

### 4. 数值稳定性告警没有隐去

补跑状态为`DIAGNOSTICS_COMPLETE_WITH_REPEAT_WARNINGS`：4个串行首窗口的整次重复前向region_mass最大差约0.00104–0.00196，超过原上限0.0001；其中一个p_class最大差1.13e-6略超1e-6。Gaussian及membership比较通过，4例最终packed输出差异比例均0。同一次原生seed/memory重放D4、最终头重放、生产组装重放和参数不变检查全部严格通过。因此报告可用于定位所观察前向，但没有宣称整条GPU路径严格确定，也没有修改阈值掩盖告警。

## 下一步建议（本轮未提交）

保留A作为目前单encoder的分割参照，同时将重建/深度退化单列处理；不继续无依据延长B训练。

若继续串行路线，优先做一个单变量短测：**语义seed保留原超点Token的可学习残差**，例如`seed = LN(W_rec stopgrad(Q_rec) + gate * W_init Q_initial)`，gate从小值开始，保持3D来源身份、原梯度隔离、原Mask头、层数、训练预算和正式协议不变。这是待验证的结构假设，理由是Q_rec阶段实例区分度下降、纯串行seed依赖重建表示；它不保证修复渲染Mask读出。先验收原生Mask/最终实例召回及验证表现，不把中间层分布外头分数当验收标准。
